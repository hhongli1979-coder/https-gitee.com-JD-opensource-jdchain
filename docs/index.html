🔗 JDChain 部署指南

JDChain Blockchain Deployment Guide

📖 关于 JDChain / About JDChain

JDChain 是京东集团自主研发的区块链底层框架，支持企业级应用场景。本指南将帮助您快速部署和使用 JDChain。

JDChain is a blockchain framework independently developed by JD.com, supporting enterprise-level application scenarios. This guide will help you quickly deploy and use JDChain.

🚀 快速开始 / Quick Start

1. 克隆代码 / Clone Repository

git clone https://github.com/blockchain-jd-com/jdchain.git jdchain
cd jdchain

2. 选择分支 / Select Branch

⚠️ 注意 / Warning:
  • 不推荐使用 develop 分支，子模块代码可能未对齐
  • 建议切换到具体已发布的版本分支
  • The develop branch is not recommended as submodule code may not be aligned
  • It is recommended to switch to a specific released version branch
git checkout master

3. 设置权限 / Set Permissions

chmod +x build/*.sh

4. 构建项目 / Build Project

完整构建 / Full Build

build/build.sh --update

跳过测试构建 / Build Without Tests

build/build.sh --skipTests

首次构建 / First-time Build

build/build.sh --update --skipTests
📦 构建参数说明 / Build Parameters:
  • --skipTests: 跳过集成测试部分 / Skip integration tests
  • --update: 从远程仓库更新子模块 / Update submodules from remote repository

📦 构建产物 / Build Artifacts

构建完成后，将在以下位置生成部署包：

After the build is complete, deployment packages will be generated:

  • 网关部署包 / Gateway Package: jdchain-gateway-<version>.zip
  • 节点部署包 / Peer Package: jdchain-peer-<version>.zip
  • 位置 / Location: deploy-gateway/target 和 deploy-peer/target

💾 系统要求 / System Requirements

  • Java: JDK 8 或更高版本 / JDK 8 or higher
  • Maven: 3.6.0 或更高版本 / 3.6.0 or higher
  • 操作系统 / OS: Linux / macOS / Windows
  • 内存 / Memory: 建议 4GB 以上 / 4GB or more recommended
  • 磁盘 / Disk: 建议 10GB 以上 / 10GB or more recommended

🛠️ 使用工具 / Tools

命令行工具 / Command Line Tool

使用 jdchain-cli 可快速执行数据上链和链上数据查询

Use jdchain-cli to quickly upload data to the chain and query data on the chain

# 数据上传 / Data upload
jdchain-cli tx upload --data <your-data>

# 数据查询 / Data query
jdchain-cli query --key <data-key>

SDK

JD Chain 提供了 Java 和 Go 版本的 SDK

JD Chain provides Java and Go SDKs

  • Java SDK: Maven 依赖引入 / Maven dependency
  • Go SDK: 参照 framework-go 仓库 / Refer to framework-go repository

🔧 故障排查 / Troubleshooting

构建失败 / Build Failures

  • 检查 Java 版本 / Check Java version
  • 检查 Maven 配置 / Check Maven configuration
  • 检查网络连接 / Check network connection
  • 确认子模块正确更新 / Verify submodules are correctly updated

启动失败 / Startup Failures

  • 检查端口占用 / Check port usage
  • 检查配置文件 / Check configuration files
  • 查看日志文件 / Check log files

📝 注意 / Note:

JDChain 是一个企业级区块链平台，需要完整的基础设施部署（包括对等节点、网关等）。本文档站点可以部署到 Vercel 等静态托管平台，但实际的 JDChain 节点需要部署到支持 Java 应用的服务器环境。

JDChain is an enterprise-level blockchain platform that requires complete infrastructure deployment (including peer nodes, gateways, etc.). This documentation site can be deployed to static hosting platforms like Vercel, but actual JDChain nodes need to be deployed to server environments that support Java applications.
